# Wallpapers de personajes

Sube aquí los wallpapers desde la web de GitHub (Add file → Upload files).

**Nombre de archivo (importante):** `<personaje>-<numero>.jpg`

Ejemplos: `nico-1.jpg`, `nico-2.jpg`, `pia-1.jpg`, `berta-1.jpg`

- `<personaje>` en minúsculas y sin tildes: nico, nina, pau, pia, milo, mila, hada, hugo, rita, roco, berta, berto, bruno, lola, sira, siro, teo, tila.
- Solo `.jpg` (en minúsculas).
- Hasta 8 por personaje (-1 a -8).
- Aparecen automáticamente en la ficha del personaje, con botón de descarga. Sin tocar código.
